# Phase 4: Implementation and Testing — Reference

## Step 1: Code Writing
- **Draft Tests**: Generate test code first (unit tests, TDD approach).
- **Implement Code**: Write/generate the implementation code to satisfy tests.
- **Test**: Perform unit and integration testing.

## Step 2: System & User Acceptance Testing
- **Validate Fully**: Execute final validation against all use case requirements.
- **Confirm Acceptance**: Verify with the user that all acceptance criteria are met.

---

## Tracking File
**Save to**: `.agent/iconix/{feature-name}/phase4-{use-case}-v{N}.md`

### Required YAML Front-matter
```yaml
---
phase: 4
```

## Phase Quality Checklist
Ensure the tracking file contains:
- [ ] Pre-implementation unit tests (TDD).
- [ ] Compiling implementation code.
- [ ] Passing unit and integration tests.
- [ ] Documented results for system and user acceptance tests.
- [ ] User sign-off for acceptance criteria.
